# portfolio
# Semantic Tags Used
## 1. `<header>`
Used to contain:
- Website title
- Navigation menu
## 2. `<nav>`
Contains navigation links:
- About
- Projects
- Contact

`<main>`
Holds the main content of the webpage.
Inside `<main>` there are three sections:
<section id="about">`
Contains:
- Short biography
- Profile photo

### `<section id="projects">`
Contains:
- Grid of project cards
- Each card has:
  - Project title
  - Project description
### `<section id="contact">`
Contains:
- Contact form
- Email address
## 4. `<footer>`
Contains:
- Copyright information
- Social media links
# Heading Structure
The page uses proper heading hierarchy:
| Heading | Purpose |
|----------|----------|
| `<h1>` | Main page title (used once) |
| `<h2>` | Section titles |
| `<h3>` | Project card titles |
